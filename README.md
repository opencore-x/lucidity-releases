# Lucidity releases

This repository hosts Lucidity desktop installers, automatic update metadata, checksums, and release notes. Application source is maintained in a separate private repository.

No stable desktop release has been published yet. Installers will appear on the [Releases page](https://github.com/opencore-x/lucidity-releases/releases) after verification. Learn more at [lucidity.my](https://lucidity.my).

GitHub's automatically generated source archives contain only this distribution repository's files, not the application source. Application license terms and third-party notices accompany the installers.
